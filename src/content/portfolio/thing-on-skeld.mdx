## Description
A branching hypertext narrative built for ATLS 2200 Web at CU Boulder, Fall 2020.

You play a crewmate aboard the Skeld, a ship infiltrated by an alien impersonating one of the crew. Each page offers choices that branch the story toward different endings. The story plays inside a retro Windows 95-style desktop with three windows: a progression window that tracks the path you've taken, the story itself with audio clips at key moments, and a dashboard with a map of the ship, your task list, and which crewmates are still alive.

## Tools used
- Plain HTML and CSS, no JavaScript.
